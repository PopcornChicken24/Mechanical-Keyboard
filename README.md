# Mechanical RGB Keyboard

A mechanical keyboard featuring customizable RGB lighting and dedicated software for full control and personalization.

The included software allows you to:

* Customize keyboard lighting effects and colors
* Create and assign custom hotkeys
* Configure your keyboard settings to match your preferences

Enjoy a fully customizable typing experience with responsive mechanical switches and advanced lighting controls.
