# Mechanical RGB Keyboard

A customizable **75% mechanical RGB keyboard** designed for a compact yet efficient typing experience. Featuring a standard **ANSI layout** with a **QWERTY key arrangement**, this keyboard provides the functionality of a full-size board while maintaining a smaller, space-saving footprint.

## Features

- **Customizable RGB Lighting**
  - Full RGB backlighting with adjustable colors and lighting effects
  - Create personalized lighting profiles to match your setup

- **Keyboard Customization Software**
  - Control RGB lighting effects and brightness
  - Create and assign custom hotkeys and macros
  - Configure keyboard settings and personalize your workflow

- **75% Compact Layout**
  - Retains essential keys while removing unnecessary space
  - Includes function row, arrow keys, and navigation controls
  - Standard ANSI layout for wide compatibility

- **QWERTY Key Configuration**
  - Familiar and accessible key arrangement
  - Designed for everyday typing, gaming, and productivity

## Software

The included configuration software allows users to fully customize their keyboard experience:

- Adjust RGB colors and lighting animations
- Create custom key mappings
- Assign shortcuts and hotkeys
- Save and switch between profiles

## Overview

This keyboard combines the responsiveness of mechanical switches with advanced customization options, providing a premium typing experience for gamers, creators, and everyday users.
